# 26：v1 统一从 stdin 接收任务

日期：2026-10-14。用户确认 v1 优先精简和易读，专业 CLI Help 留作后续独立迭代。

## 决策与变化

v1 的无参数、位置参数和 -p 原本都进入同一个单任务循环。删除位置参数、-p/--print、HELP 和 -h/--help 分支后，入口顺序变为：拒绝意外参数、读取 stdin、检查任务大小和空输入、读取配置、构建 Config。终端读一行，管道读完整内容；一次任务结束后退出。误传参数返回英文错误并指向 README；空输入和 EOF 在加载配置前结束。

环境变量由 README 与 .env.example 说明。main 已有多轮聊天，保留其 -p 单次执行语义。本次不改变 main 的运行入口。未来帮助按用途、Usage、分组、对齐、高亮与颜色设计，并支持窄终端、无颜色输出和无需凭证查看；详见 [CLI Help 决策](../cli-help-plan.md)。

CLI 和协议测试改用 stdin；实时验收脚本通过 communicate(input=task) 传入任务。教程第 05 章的两类任务命令改用管道。最后一个重建补丁从实际应用完 00–05 的文件集生成，同时纳入此前的英文代码文本与空行整理，保证完整 src 与当前 v1 一致。历史步骤和真实模型记录保留原来源。

当前生产 Rust 为 388 代码行 / 402 物理行（此前为 399/413），其中 CLI 为 62 代码行。减少 11 代码行来自入口分支与完整 Help 的删减，没有压缩排版或移走运行代码。
