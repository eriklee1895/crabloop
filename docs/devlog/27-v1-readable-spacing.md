## 排版约定

独立顶层定义之间留一空行；函数内按逻辑阶段分段，紧密相关的语句保留在一起。比如读取 task 后，用一空行开始大小与空输入检查；读取 .env 后，再进入配置查询与 provider 选择。校验与被校验的操作不机械地逐行分开。

- cli.rs：参数限制、任务读取、任务校验、配置加载、查询规则、provider 和 Config 构建。
- lib.rs：准备循环状态、请求预算、模型响应、历史与结束判断、执行工具与回传结果。
- model.rs：HTTP 返回、响应校验、解析状态、不同 output item 的处理、最终结果。
- tools.rs：schema 构建、UTF-8 截断、参数与路径校验、文件操作、输出采集、超时结果处理。
- main.rs：导入与入口、配置、执行、显示结果和退出状态。
