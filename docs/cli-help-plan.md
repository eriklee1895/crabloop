# CLI Help：在后续独立迭代中完成

2026-10-14 确认。v1 首先让读者快速读懂手写 agent loop，生产源码保持精简和正常排版。启动统一从 stdin 接收一次任务，终端读一行、管道读完整内容；完成后退出。删除任务参数和完整 HELP，README Quick Start 与 .env.example 负责启动及配置说明。意外参数、缺少密钥和无效配置仍要有具体英文错误。

main 已有多轮聊天，单次执行参数在那里有实际用途；不把 v1 的删减应用到 main 的运行入口。历史标签和验收记录保留当时的接口与结果。

## 未来的独立增量

当命令行参数、运行模式和配置入口增多时，专门完成一轮 CLI 设计，不必等到完整 TUI。参考用户提供的 Cargo、Codex 帮助截图，目标是清楚的信息层次、对齐、强调和有语义的颜色；不为模仿截图而增加没有实际用途的命令。具体版本和参数解析库留到该增量开始时确定。

验收要求：

- 用途、Usage、参数分组和可复制示例有清楚的阅读顺序。
- 参数、占位符、标题与说明有一致的视觉样式；全英文 UI 文案。
- 窄终端合理换行；关闭颜色后仍可读；输出重定向时不留下多余的控制字符。
- 查看帮助无需 API key，不加载模型配置、不创建会话、不发起模型请求。
- 参数解析与帮助来自同一份声明，避免维护巨大的转义字符串和重复文案。
- 帮助展示与实际支持的命令、默认值、配置优先级一致。

该增量与聊天记录渲染、Markdown、slash command 和完整终端布局分别实现和验收。v1 不引入彩色 Help 或新的 CLI 框架。
