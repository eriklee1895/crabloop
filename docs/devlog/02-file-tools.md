# 02：文件工具与精确修改

日期：2026-10-11。代码书签：step-02-file-tools。

先写读写、关联结果、唯一替换、无效参数、路径和 UTF-8 边界测试。空实现时 6 项失败、1 项只检查拒绝/不变的测试通过；实现后 7 项通过。

进一步用“你你好”与 7 字节文件上限复现了错误分类问题：读取上限+1 字节后，read_to_string 在大小检查前报无效 UTF-8。新增测试先失败，修正为先读取有限字节、检查长度、再解码后通过。

精确修改使用 find 与 rfind 核对唯一位置，因此重叠出现的片段也不会被当成唯一匹配。所有匹配和大小验证都在磁盘写入前完成；当前写入本身不提供事务或原子回滚。

Clippy 指出了测试中两处 Default 后重新赋字段的写法，已改为结构更新语法。测试用临时目录执行真实文件操作，没有模拟文件系统。

验证命令：cargo test --locked；cargo clippy --locked --all-targets -- -D warnings。这里的通过是文件工具与本地协议证据，尚未连接真实模型行动循环。
