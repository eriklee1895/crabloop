# v3 第一步：clap 与 CLI Help

v3 首个增量使用 clap，统一 main 的参数解析与 CLI Help，尚未实现。v1 保留 stdin 入口：终端连续提问，管道单次执行。

## 已确定的排期与范围

接管 main 已有参数，提供清楚的 Usage、分组、示例与颜色；实施时锁定兼容的 clap 版本。

实施顺序：

1. 先迁移 main 已有参数：默认聊天、-p/--print、位置任务、stdin 管道、--chat 和 --workspace。保留正常运行语义，以同一份参数声明生成帮助和错误提示。
2. 提供标准 --help/-h、--version/-V；版本来自 Cargo package metadata，无需密钥或模型配置。REQ-021 的 version 子命令仍独立待排期，本步不占用已有的位置任务文本。
3. 后续逐步实现 TOML/provider，再实现模型目录；能力落地后才增加相应参数或子命令。SSE、终端渲染和配置加载分别实现、分别验收。

clap 只负责 CLI 参数与帮助，agent loop 保持手写。

验收要求：

- 用途、Usage、参数分组和可复制示例有清楚的阅读顺序。
- 参数、占位符、标题与说明有一致的视觉样式；全英文 UI 文案。
- 窄终端合理换行；关闭颜色后仍可读；输出重定向时不留下多余的控制字符。
- 查看帮助无需 API key，不加载模型配置、不创建会话、不发起模型请求。
- 参数解析与帮助来自同一份声明，避免维护巨大的转义字符串和重复文案。
- 帮助展示与实际支持的命令、默认值、配置优先级一致。
